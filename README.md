# Weather App 🌦️

A simple and user-friendly Weather App that displays current weather information and a 7-day weather forecast for a searched city.

## Features
- Search for a city
- View current weather information
- Check temperature and weather conditions
- View a 7-day weather forecast
- Responsive and easy-to-use interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Open-Meteo API

## Project Files
- `index.html` – Structure of the application
- `style.css` – Styling and layout
- `script.js` – Weather data and application functionality

## How to Run
1. Download or clone this repository.
2. Keep all three project files in the same folder.
3. Open `index.html` in your web browser.
